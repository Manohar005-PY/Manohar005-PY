## Selected Projects

### IncidentHub
*A Spring Boot incident management application.*

Building REST APIs for incident creation and status management, with input validation, database persistence, migrations, and automated tests.

**Stack:** Java · Spring Boot · PostgreSQL · Flyway · JUnit · Mockito

### FlowForge
*A distributed background job processing prototype.*

A job processing system built around asynchronous execution, worker registration, heartbeat tracking, retries, and failure handling.

**Stack:** Python · FastAPI · PostgreSQL · Redis · SQLAlchemy · Docker

*An order and inventory management backend.*

A backend application covering product management, inventory operations, order workflows, and payment handling, with a focus on service boundaries and transactional consistency.

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · Alembic

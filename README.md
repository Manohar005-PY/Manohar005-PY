### ⚙️ FlowForge — Job Queue Backend *(in progress)*
**Python · FastAPI · PostgreSQL · SQLAlchemy · Alembic · Redis · Pydantic · Docker Compose**

A backend project exploring persistent job submission and the architecture of reliable asynchronous systems.

- REST endpoints for creating and retrieving jobs
- Job persistence in PostgreSQL with Alembic migrations
- Redis integration for enqueueing job IDs
- Job metadata for status, priority, retry limits, scheduling, and execution timestamps
- Layered design: routes, services, repositories, database, and queue
- Investigating transaction boundaries and consistency between PostgreSQL and Redis
- **Next up:** worker execution, job processing, and retry handling

### ☕ IncidentHub — Java Spring Boot REST API *(in progress)*
**Java · Spring Boot · Spring Web · Maven · JUnit-style testing**

A backend project for learning incident-management API design with separated controller and service layers.

- REST controller and service logic for open and resolved incidents
- Dependency injection and Spring application-context configuration
- Service-level automated tests
- Working on database persistence and integration testing

### 🤖 SupportDesk — Support Ticket Classification
**Python · scikit-learn**

## What I’m focused on

I’m spending time on backend fundamentals rather than collecting frameworks: API design, database modelling, transaction boundaries, validation, testing, and error handling. I’m also interested in how asynchronous systems coordinate work and recover from failure.

## Projects

**IncidentHub** · *In development*

A Spring Boot incident-management API. I’m using it to work through REST design, request validation, persistence, status transitions, database migrations, and controller/service testing.

`Java` · `Spring Boot` · `PostgreSQL` · `Flyway` · `JUnit` · `Mockito`

**FlowForge** · *Prototype*

A background job-processing system with a Redis-backed queue, worker registration and heartbeats, retry handling, and execution tracking.

`Python` · `FastAPI` · `PostgreSQL` · `Redis` · `SQLAlchemy` · `Docker`

**OrderFlow** · *Functional project*

An order and inventory backend covering products, stock operations, orders, and payments. The main learning focus has been service boundaries, database transactions, and schema migrations.

`Python` · `FastAPI` · `PostgreSQL` · `SQLAlchemy` · `Alembic`

## Engineering principles

I value correctness over cleverness, explicit transaction boundaries, useful tests, clear error handling, and code that another person can understand and maintain.

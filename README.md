## `01` / About Me

I'm a Computer Science student interested in building software that is reliable, maintainable, and useful.

My primary focus is **backend engineering** — understanding how applications work beyond the user interface, from API design and database transactions to background processing and distributed systems.

I enjoy taking ideas, breaking them into smaller engineering problems, and implementing them step by step.

- Currently focusing on **Python backend development**.
- Exploring **Java and Spring Boot**.
- Interested in databases, distributed systems and software architecture.
- Learning through building, debugging, testing and contributing to real codebases.
- Open to software engineering and backend development internship opportunities.

## What I'm working on

### FlowForge — Distributed Job Execution Platform

A distributed system for submitting, scheduling, executing, and tracking background jobs across workers.

**Exploring:**

* job queues
* worker coordination
* retries & failure handling
* idempotency
* concurrency
* task state management
* observability
* distributed-system trade-offs

> Currently in development.

### OrderFlow — Backend Order Management System

A backend system built to understand how real applications handle **transactions, inventory, orders, payments, and data consistency**.

**Built with:**

`Python` · `FastAPI` · `PostgreSQL` · `SQLAlchemy` · `Alembic` · `Docker`

The project pushed me beyond simply making APIs work and into questions around:

* transaction boundaries
* service vs repository responsibilities
* database consistency
* relational modeling
* failure handling
* authentication & authorization

> Functional and documented.

### PRISM

A college research project involving computer vision/perception.

This project is part of my academic work and represents an earlier stage of my engineering journey.

## Engineering Principles

I try to build around a few simple ideas:

> **Understand before abstracting.**

> **Correctness before scale.**

> **Make failure visible.**

> **Prefer simple systems that can be reasoned about.**

> **Don't use complexity to compensate for a lack of understanding.**
